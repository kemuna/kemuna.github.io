# Kemuna — портфоліо

![Прев’ю портфоліо Kemuna](public/branding/social-preview.png)

Особистий сайт-портфоліо Єлизавети Данченко (`kemuna`) — графічної дизайнерки
та 2D-художниці.

[Переглянути сайт](https://kemuna.github.io/)

## Можливості

- Англійська й українська версії з автоматичним визначенням мови.
- Світла й темна теми зі збереженням вибору відвідувача.
- Адаптивні галереї робіт із досвіду та власних ілюстрацій.
- Повноекранний перегляд зображень із керуванням кнопками, клавіатурою та
  свайпами.
- Адаптивні WebP-зображення та відкладене завантаження вмісту галерей.
- Переходи між сторінками, анімації появи під час прокручування та підтримка
  режиму зменшеного руху.
- Доступна навігація, елементи керування, стани фокуса й описи зображень.
- Власна іконка сайту, прев’ю для поширення посилань і локалізовані сторінки
  404.

Індексацію пошуковими системами навмисно вимкнено. Портфоліо призначене для
поширення за прямим посиланням, водночас боти Telegram, LinkedIn та інших
сервісів можуть завантажувати прев’ю сторінок.

## Технології

- [Astro](https://astro.build/) для статичної генерації сайту й оптимізації
  зображень.
- TypeScript для інтерактивних компонентів.
- Звичайний CSS для адаптивної верстки, тем і анімацій.
- JSON-файли для англійських та українських перекладів.
- Локально підключені шрифти Manrope та Onest.
- GitHub Pages і GitHub Actions для хостингу та розгортання.

Збірка для публікації містить лише статичні HTML, CSS і JavaScript. Для роботи
сайту не потрібні сервер або база даних.

## Локальний запуск

Необхідно встановити Node.js 22 LTS або Node.js 24 LTS. Рекомендовану версію
також зазначено у файлі `.nvmrc`.

```bash
npm install
npm run dev
```

За замовчуванням локальний сервер буде доступний за адресою
`http://localhost:4321/`.

Якщо PowerShell у Windows блокує `npm.ps1`, використовуйте `npm.cmd install` та
`npm.cmd run dev`.

Корисні команди:

```bash
npm run build
npm run preview
```

Готова збірка для публікації записується до каталогу `dist/`.

## Локалізація

Англійська й українська версії мають окремі статичні маршрути:

- `/en/`
- `/uk/`

Переклади зберігаються у файлах `src/i18n/en.json` і `src/i18n/uk.json`.
Коренева сторінка перенаправляє відвідувача на збережену мову, а під час першого
відвідування — на мову, яка найкраще відповідає налаштуванням браузера.

## Структура проєкту

```text
src/
  assets/           Фото профілю, роботи з досвіду та ілюстрації
  components/       Сторінки й спільні інтерактивні компоненти
  i18n/             Англійські та українські переклади
  layouts/          Спільний макет документа й метадані
  pages/            Локалізовані статичні маршрути та сторінки 404
  utils/            Допоміжні функції адаптивних зображень галереї
  style.css         Глобальні стилі, теми й адаптивний дизайн
public/
  branding/         Зображення прев’ю для соціальних мереж
  cursors/          Власні курсори для світлої й темної тем
  robots.txt        Правила для пошукових ботів і ботів прев’ю
```

## Розгортання

Після надсилання змін до гілки `main` GitHub Actions збирає Astro-проєкт і
публікує каталог `dist/` на GitHub Pages. Коміти, які змінюють лише файли README,
не запускають збірку та розгортання сайту.
